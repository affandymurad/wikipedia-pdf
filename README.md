# Wikipedia-PDF

Turn a Wikipedia article into a neatly laid-out PDF. The PDF is built directly from the article content, not printed from the web page.

**Live:** https://wikipedia-pdf.web.app/

## Features

- Table of contents linked to headings inside the PDF, plus PDF bookmarks
- Images with captions, tables, infoboxes (including sidebar-style boxes), lists and references
- `[1]` citation markers that jump to the reference list
- Attribution page with text contributors and image licenses (CC BY-SA 4.0)
- Works for any `*.wikipedia.org` language edition, and for a specific revision via `oldid`
- Special **Abstract Wikipedia** edition (`abstract.wikipedia.org`)
- Bilingual interface (English / Indonesian)
- No server: everything runs in the browser with [jsPDF](https://github.com/parallax/jsPDF) and jsPDF-AutoTable

## Query parameters

The page can be opened with a URL so the field is filled in and the PDF is created right away.

| Parameter | Description |
| --- | --- |
| `url` | Wikipedia article URL. Encode it when it contains its own `?`/`&`, or put `oldid` / `curid` next to it. |
| `oldid` | Specific revision of the article. |
| `auto=0` | Only fill in the URL field; do not create the PDF automatically. |
| `lang` | Interface language, `id` or `en`. Order of precedence: `?lang=`, the saved choice, then `en`. |

```
https://wikipedia-pdf.web.app/?url=https://en.wikipedia.org/wiki/Indonesia
https://wikipedia-pdf.web.app/?url=https://id.wikipedia.org/wiki/Indonesia&oldid=123456&lang=id
https://wikipedia-pdf.web.app/?url=https://id.wikipedia.org/wiki/Indonesia&auto=0
```

### Abstract Wikipedia

```
https://wikipedia-pdf.web.app/?url=https://abstract.wikipedia.org/wiki/Q252%3Fuselang%3Did
```

- Q-id pages only. No nested headings, tables, infoboxes or references, and `oldid` is not supported. The PDF contains only the paragraphs and images that Abstract Wikipedia has generated, so it is much shorter than a regular article.
- The text language is set with `?uselang=` **inside** the abstract URL (default `en`). This is separate from `lang`, which only controls the interface.
- The text is generated by the Abstract Wikipedia server from Wikifunctions functions, not by this project. Languages other than English are often incomplete or empty ("Content pending"). When there is no text at all in the requested language, English is used automatically and a note is added to the progress log.
- The API used (`abstractwiki_fetch_section`) is internal and undocumented. It may change and sometimes rate-limits requests (HTTP 429), so some sections may be skipped.

## Run locally

It is a static site (`index.html` plus `fonts/`). Serve it over HTTP; opening the file directly with `file://` blocks loading the fonts.

```bash
npx serve .
```

## Deploy

Hosted on Firebase Hosting (project `wikipedia-pdf`). Firebase serves the `public/` folder, which is a copy of `index.html` and `fonts/` and is not committed.

```bash
mkdir -p public && cp -r index.html fonts public/
firebase deploy --only hosting
```

## Notes

- Wikipedia text is licensed under CC BY-SA 4.0. Attribution and the contributor list are included in every PDF.
- Fonts: Roboto (see `fonts/README.txt`).
- Non-Latin scripts are drawn as images in the PDF, so that text cannot be searched and the file is larger.

## Ringkasan (Bahasa Indonesia)

Wikipedia-PDF mengubah artikel Wikipedia menjadi PDF yang tertata, lengkap dengan Daftar Isi berlink, gambar, tabel, infobox, referensi, dan halaman lisensi. Semua diproses di peramban tanpa server. Tempel URL artikel, atau buka lewat query seperti `?url=https://id.wikipedia.org/wiki/Indonesia&lang=id`. Edisi khusus Abstract Wikipedia juga didukung dengan beberapa limitasi (lihat bagian di atas).
